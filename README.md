## 🔬 Методологія дослідження

### 1️⃣ **Розвідувальний аналіз даних (EDA)**
- Аналіз розподілу продажів по магазинах та товарах
- Виявлення сезонних паттернів та трендів
- Візуалізація динаміки з довірчими інтервалами
- Аналіз пропущених значень та викидів

### 2️⃣ **Декомпозиція часового ряду**
- Адитивна декомпозиція на тренд, сезонність, залишки
- Аналіз стаціонарності (ADF тест)
- Визначення необхідності диференціювання

### 3️⃣ **Feature Engineering**
- **Дата-ознаки**: рік, місяць, день тижня, квартал
- **Лагові ознаки**: продажі за попередні дні
- **Rolling статистики**: ковзні середні, мін/макс
- **Сезонні індикатори**: вихідні, свята, початок/кінець періодів

### 4️⃣ **Статистичний аналіз**
- **PACF аналіз** для визначення оптимальних лагів
- **Тест сезонності** за допомогою Darts
- **Аналіз автокореляції** та стаціонарності

## 🤖 Моделі прогнозування

### 📊 **Baseline моделі (Наївні)**
| Модель | Опис | MAPE |
|--------|------|------|
| `NaiveSeasonal` | Повторення сезонного паттерну | ~15-25% |
| `NaiveDrift` | Лінійний тренд з останніх даних | ~20-30% |
| `Ensemble` | Комбінація сезонної та трендової | ~12-22% |
| `Improved` | Адаптивний тренд + сезонність | ~10-20% |

### 🧠 **Машинне навчання**
| Модель | Технологія | Особливості | MAPE |
|--------|------------|-------------|------|
| `XGBoost Basic` | Gradient Boosting | Автоматичні лаги | ~8-18% |
| `XGBoost Enhanced` | + Feature Engineering | 20+ ознак | ~6-15% |

### 📈 **Класичні статистичні моделі**
| Модель | Тип | Параметри | MAPE |
|--------|-----|-----------|------|
| `Simple ES` | Exponential Smoothing | α (рівень) | ~15-25% |
| `Holt's ES` | + Тренд | α, β | ~12-20% |
| `Holt-Winters` | + Сезонність | α, β, γ | ~8-18% |
| `ARIMA` | Ручний підбір | (p,d,q) | ~10-20% |
| `AutoARIMA` | Автоматичний | Оптимізовані параметри | ~7-17% |

### 🔮 **Сучасні моделі**
| Модель | Технологія | Особливості | MAPE |
|--------|------------|-------------|------|
| `Prophet` | Facebook Prophet | Автосезонність + тренди | ~7-20% |
| `RNN/LSTM` | Глибоке навчання | Нелінійні залежності | ~8-22% |

### 🔄 **Бектестування та валідація**

| `Time Series Split` | Хронологічне розділення | Репрезентативна оцінка |
